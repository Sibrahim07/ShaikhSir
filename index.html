1. Introduction to Variables

In Python, variables are created when you assign a value to them. Let's practice creating a string variable and printing it.

PYTHON
# Create a variable named 'course'
course = "Shaikh Sir"
print("Welcome to " + course)

2. Dynamic Typing in Python

Python is dynamically typed, meaning you don't need to declare a variable's type when you create it. Types are determined at runtime.

PYTHON
x = 42      # x is an integer
x = "DevOps" # x is now a string
print(x)

3. Writing Your First Function

Define reusable code block with def. Let's make a greeting utility.

PYTHON
