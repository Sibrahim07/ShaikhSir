What is Kubernetes

Lesson

Kubernetes (k8s) is an open-source container orchestration platform originally designed by Google. It automates the deployment, scaling, load balancing, health recovery, and operational lifecycle of containerized applications across clusters of physical or virtual machines.

Why Kubernetes is Essential

While Docker runs containers on single servers, modern web apps require hundreds of containers spanning multiple cloud availability zones. Kubernetes manages this complexity by handling:

  • Auto-Healing: Restarts containers that fail, replaces pods, and reschedules them when nodes die.
  • Horizontal Scaling: Scales workloads dynamically based on CPU/memory usage or custom metrics.
  • Service Discovery & Load Balancing: Exposes containers using stable DNS names and distributes traffic.
