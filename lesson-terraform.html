What is Infrastructure as Code

Lesson

Terraform by HashiCorp is an industry-standard Infrastructure as Code (IaC) tool. It allows cloud engineers to safely and predictably provision, version, and manage infrastructure across public cloud platforms such as AWS, Azure, and Google Cloud using human-readable configuration files.

Why Infrastructure as Code?

Manually configuring servers, VPCs, and databases through cloud web consoles is slow, error-prone, and cannot be easily reviewed in Git pull requests.

With Terraform, your infrastructure is defined as declarative code in HashiCorp Configuration Language (HCL). You can test changes, track history, roll back mistakes, and duplicate entire staging/production environments with a single command.
